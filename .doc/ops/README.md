# ops/ — runbook e utility operative

Questa cartella è riservata a materiale operativo di supporto (facoltativo), ad esempio:
- runbook sintetico (comandi ricorrenti)
- checklists di verifica (audit, news, forecast)
- esempi di output atteso

Le evidenze “ufficiali” e tracciabili rimangono nei report sotto `../reports/` e nei canonici progetto.
