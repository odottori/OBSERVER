# Architettura (as-built)

Layer principali (v1.2.5):

- **Infrastructure**: ambiente, config, schema DB, disciplina run/session
- **Data plane**: ingestion + validation + storage
- **Signal plane**: features, segnali, forecasting, ranking
- **Governance plane**: audit, traceability, evidence pack
- **Execution plane**: risk / OMS / paper / live broker adapters
- **Monitoring plane**: TCA, drift, alerting
